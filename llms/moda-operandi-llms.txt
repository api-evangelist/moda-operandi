# Moda Operandi

> Moda Operandi is a New York-based luxury fashion e-commerce marketplace founded in 2010, built
> around the "trunkshow" model — customers pre-order directly from designers' full runway
> collections weeks before the clothes reach stores — alongside an in-season boutique carrying
> more than 1,000 brands across ready-to-wear, fine jewelry, home and beauty.

## What Moda Operandi publishes for developers

Nothing. There is no developer portal, no API documentation, no API reference, no OpenAPI or
Swagger definition, no SDK, no CLI, no webhook or event surface, no MCP server, no A2A agent card,
no /.well-known/ document of any kind, no status page, no changelog, no security.txt and no
published rate limits. This file was GENERATED by API Evangelist from what could be observed
publicly on 2026-08-25; Moda Operandi does not serve an llms.txt of its own
(https://www.modaoperandi.com/llms.txt returns a 301 into the storefront's 404 page).

## The one machine-readable contract that does exist

Moda Operandi operates a first-party GraphQL API that powers search and browse on its own
storefront. It is undocumented, but it is public and it answers anonymous introspection.

- [Search API endpoint](https://search.modaoperandi.com/graphql): GraphQL. Read-only — the schema
  declares a Query root and no mutation or subscription root. 37 query fields, 121 types.
- [Introspected schema (SDL)](https://raw.githubusercontent.com/api-evangelist/moda-operandi/refs/heads/main/graphql/moda-operandi-search-schema.graphql)
- [Raw introspection response](https://raw.githubusercontent.com/api-evangelist/moda-operandi/refs/heads/main/graphql/moda-operandi-search-introspection.json)
- [Notes on the schema, its shape and its caveats](https://raw.githubusercontent.com/api-evangelist/moda-operandi/refs/heads/main/graphql/moda-operandi-graphql.md)

What it covers: keyword search and autocomplete; faceted product listings; designers; trunkshows;
looks; product variants; gift categories; editorial slides; and Algolia-backed recommendations
(bought_together, looking_similar, related_products, trending_items).

What it does not cover: cart, checkout, accounts, orders, returns. Those route to a separate REST
host, https://api.modaoperandi.com/public, which publishes no specification and returns HTTP 404
for every anonymously probed path.

Minimal working call:

    curl -s https://search.modaoperandi.com/graphql \
      -H 'Content-Type: application/json' \
      -d '{"query":"{ version }"}'

## Warnings for an agent considering this API

- It is an internal surface, not a product. There is no stability contract, no SLA, no support
  channel and no terms that address programmatic use — https://www.modaoperandi.com/terms governs
  the consumer storefront.
- Twelve of the 37 root query fields are already marked @deprecated in the schema, with no dates
  and no removal policy. Ten of them say "use product_listing instead".
- Errors return a full server-side stacktrace with absolute filesystem paths.
- No rate-limit headers are emitted, so there is no back-off signal to respect. Be conservative.
